Manufacturing Tools Hub - version avec Supabase source de vérité + loupe de recherche

Inclus :
- Création de compte libre avec email + mot de passe.
- Rôles user / expert / admin dans Supabase.
- Bibliothèques CNC, Hot Stamping et Laser lues depuis Supabase.
- Bouton loupe entre l’encart blanc et le bouton + pour rechercher machine, matière, outil, support, folio, paramètre.
- La sélection via loupe remplit automatiquement le champ et les paramètres liés.
- Modification des paramètres depuis les apps pour expert/admin.
- Traçabilité : chaque ajout/modification/calibration stocke l’email utilisateur.
- Historique dans library_history.

Installation :
1. Dans Supabase, exécuter supabase_setup_full.sql.
2. Remplacer le dépôt GitHub avec ce ZIP.
3. Commit changes.
4. Attendre Vercel.
5. Ctrl + Shift + R.

Important : par défaut, un nouveau compte reçoit le rôle user. Pour autoriser la modification des bibliothèques, mettre son rôle à expert ou admin dans la table user_roles.
